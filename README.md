# Smart Traffic Lights Using Local AI — IEEE LaTeX Template & Literature Review

This repository contains an IEEE conference paper implementation based on the **"AI-Assisted Research & LaTeX Workshop"** hands-on assignment. The paper explores adaptive traffic signal control, comparing fixed, cloud-based, and local edge computing architectures, while highlighting key research gaps in emergency vehicle routing.
